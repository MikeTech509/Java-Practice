# Java Practice Projects

## Overview
This repository contains beginner Java programs focused on strengthening core programming concepts. The projects practice object-oriented programming, arrays of objects, and basic search algorithms.

## What’s Included
- Object-oriented programming (classes and constructors)
- Arrays of objects
- Sequential search algorithm
- String handling and comparison methods

## Project Example
One of the programs allows the user to:
- Input a list of film titles
- Store them in an array of objects
- Search for a specific film using sequential search
- Display whether the film exists in the collection

## Skills Practiced
- Java syntax and structure
- Object-oriented programming (OOP)
- Methods and parameter passing
- Arrays and loops
- Basic algorithm design (linear search)

## Purpose
This repository is part of my learning journey in Java programming and is used to practice problem-solving and improve coding skills step by step.
